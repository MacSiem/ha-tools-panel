# HA Tools Panel

![HA Tools Panel Screenshot](screenshot.png)

Main dashboard panel for all HA Tools addons. Provides a unified Modern Bento Light Mode interface with quick access to all tools.

## Installation

### HACS (recommended)

1. Open HACS in Home Assistant
2. Go to **Frontend** section
3. Click the three dots menu > **Custom repositories**
4. Add `https://github.com/MacSiem/ha-tools-panel` as **Dashboard**
5. Install **HA Tools Panel**
6. Restart Home Assistant

### Manual

Copy the contents to `/config/www/community/ha-tools-panel/`

## Design

Uses **Modern Bento Light Mode** design system:

- Background: `#F8FAFC`
- Primary: `#3B82F6`
- Text: `#1E293B`
- Border: `#E2E8F0`
- Font: Inter, 16px border-radius, smooth animations
